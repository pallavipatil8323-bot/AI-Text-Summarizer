# AI Text Summarizer

## Project Title

**AI Text Summarizer**

## Problem Statement

Reading long documents can be time-consuming. This project helps users quickly understand lengthy text by generating a shorter summary and highlighting important key points.

## Assigned Features

* Text input
* File upload
* Adjustable summary length
* Generate summary
* Display key points
* Word count and reduction percentage
* Copy summary
* Clear input

## Features Implemented

All the assigned features have been implemented with a simple and responsive user interface.

## Technologies Used

* HTML5
* CSS3
* JavaScript

## AI Tools Used

**ChatGPT** was used for:

* Code generation and improvement
* UI design ideas
* JavaScript summarization logic
* Debugging
* README documentation

## Important AI Prompts / Uses

* Create a responsive AI text summarizer using HTML, CSS and JavaScript.
* Add text and file input functionality.
* Add an adjustable summary length slider.
* Generate summaries and display key points.
* Add word count and summary reduction statistics.
* Debug and improve the website code.

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Enter text or upload a `.txt` file.
5. Adjust the summary length and click **Generate Summary**.
